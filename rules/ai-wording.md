# AIらしい言い回しを消すための語彙と確認（ai-wording）

`rules/slide-rules.md` C-5 から参照する。メッセージライン・本文・ノートの仕上げ前に、この一覧で読み直す。
考え方は Jinba consulting-pptx-skill（github.com/carnot-tech/jinba-consulting-pptx-skill、MIT License）の `references/ai-smell-lexicon.md` を参考に、本ルール（である調・2行メッセージ・14pt以上）に合わせて書き直した。

## 1. 消す語・置き換える語

| 種類 | 例 | 直し方 |
| --- | --- | --- |
| 中身のない強調 | まさに、非常に、極めて、大きく、圧倒的に、画期的、抜本的 | 数字か比較対象に置き換える（「大きく減った」→「10年で3割減った」） |
| カタカナの盛り | ソリューション、シナジー、シームレス、インサイト、バリュー、エンドツーエンド | 日本語の具体語にする（「シナジー」→「窓口を共通にして費用を減らす」） |
| 名詞に畳んだ行政・ビジネス語 | 推進、強化、活用、高度化、最適化、効率化、実現、創出、寄与、担保、〜に資する | 「誰が・何を・どうする」の動詞に戻す（「連携強化」→「市と事業者が予約データを共有する」） |
| 枕と締めの定型文 | 近年、昨今、変化の激しい時代、以上のことから、今後検討していく、引き続き取り組む | 消す。先送りの文は「いつ・誰が・何を出すか」を書くか、行ごと消す |
| 断定を避ける語尾 | 〜と言えるでしょう、〜と考えられます、〜の可能性がある（根拠で言い切れるのに） | 根拠の強さに合わせて言い切る（A-2）。弱める必要があるときは理由を書く |
| 抽象の水増し | 〜という観点から、〜の側面、重要なポイント、鍵となる、多角的に、包括的に | 消すか、観点の中身を名指しする |
| 作り手側の語 | Situation／Complication／Resolution、ロジックツリー、MECE、ゴーストデッキ | 紙面に出さない。「これまでの前提／課題／打ち手」のように中身の言葉にする |
| 口語・内輪の略語 | コスパが悪い、ちゃんと、普通に、ネタ、手当て済み | 書き言葉にする（「桁違いに割高」「既存の制度で対応している」） |

## 2. 崩す構文

- 「ポイントは3つ」「まず・次に・最後に」のような枠だけの前置き → 中身から書き始める。
- 「〜し、〜し、〜する」の三点連結や、体言止めの対句の連打 → 1文1主張に分ける。
- 接続詞を毎文の頭に置く（また、さらに、加えて、したがって） → 大半は消せる。
- 抽象名詞を主語にした受け身（「〜の改善が図られる」） → 「誰が何を改善する」に開く。
- 完了と進行の取り違え（「導入した」と「導入中」） → 事実に合わせる。
- 「御社」 → 書き言葉では「貴社」。

## 3. 装飾で盛らない

- 絵文字、記号の見出し飾り、信号機の赤・黄・緑の表、太字の乱用はAIが作った印象を強める。強調はB-3のとおり1スライド1点。

## 4. 仕上げ前の30秒確認

1. メッセージライン一覧を上から声に出して読み、話し言葉として自然か。
2. 消せる語（強調・枕・締め・接続詞）を消したか。
3. 名詞に畳んだ語を「誰が・何を・どうする」に開いたか。
4. 数字・固有名詞・時期が入るべき場所に入っているか。
5. 1つの文章の塊に2文以上を詰めていないか。
