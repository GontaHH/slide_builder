# パターン定義（P01〜P80）

consulting-slide-builder が各スライドの型を選ぶための定義。見本は同じフォルダの pattern-deck.pptx の同じIDのスライド。型は「発想帳」であり、伝えたいことを先に決めてから選ぶ。
座標は標準サイズ（27.52×19.05cm = 780×540pt）基準。共通枠（メッセージブロック・スライドタイトル・出所・ページ番号）は全パターン同じ位置。
矢印・符号・印の決まりは `docs/symbols.md`（見本デッキ S01〜S04）、アイコンは `docs/icons.md`（同 I01〜I04、SVG は `templates/icons/`）。

## パターンごとの作法と、よくある失敗

- **P01**：章の結論を並べるだけで議論の全体が分かること。失敗：箇条書きの羅列で、どれが結論か分からない。
- **P03／P09**：CAGRや差分の注釈は1つだけ。失敗：全ての棒を同じ濃い色にする、目盛り線を残す。
- **P04**：必ず降順。失敗：五十音順や地域順で並べ、比較が読めない。
- **P05／P18**：系列名は凡例ではなく右端に直接書く（P18は上部の凡例で可）。失敗：系列が6つ以上。
- **P06**：始点・終点はGray2、要因はGray1。増減は「＋」「−」で示し、赤緑で塗り分けない。
- **P07**：規模かシェアの片方しか議論しないなら、P04やP05で足りる。
- **P10**：チャート上の番号と右欄の番号を対応させる。失敗：右欄が長文になる。
- **P11**：2つのエクジビットは必ず左右。上下に積まない。左右の見出しの線の高さと、行の高さ・上端をそろえる（同じ行に対応する項目を置く）。失敗：項目を1つずつ箱で囲み、左右の対応が読めない。
- **P12**：アイコンは単色の線画で統一。矢印には流れるもの（資金・データ・人）を書く。失敗：塗りつぶしの色付き箱を並べる。
- **P13**：段階を矢羽の列見出しにし、左の行見出し（期間・主な取組・判断の基準・担い手）で中身を並べる。判断点（◆）と条件を書く。失敗：工程を並べただけで何を決めるかが分からない、矢羽の下が空く。
- **P14**：演算子（×＋）を書く。失敗：MECEでない分解。
- **P15**：軸の定義と象限の意味を書く。失敗：軸の向き（高・低）が不明。
- **P16**：評価基準は注記で定義する。失敗：全セルに色を付ける。
- **P17**：成功の鍵を1行で書く。失敗：事例の説明が長文になる。
- **P19**：施策は動詞で終え、番号と着手時期を付ける。
- **P20**：数値の算定前提を補足（11pt）に書く。

- **P21**：左の図にない項目を右で論じない。中央の三角は強い因果があるときだけ。失敗：右の読み取りが図と無関係な一般論になる。
- **P22**：課題は「未達の原因」だけを書き、解決と1対1で対応させる（同じ行に置く）。項目は箱で囲まず、見出しの線と行の線で組む。失敗：課題欄に現状の説明を並べる、箱を6つ並べる。
- **P23**：打ち手のない課題、課題のない打ち手を作らない。向きは見出しの行の三角1つで示し、行ごとに矢印を引かない。失敗：打ち手が課題の言い換えになる、課題と打ち手を箱で囲んで矢印でつなぐ。
- **P24**：各工程に期間・やること・担当・終わりの条件を、工程と1対1の列で書く。失敗：工程名だけで中身がない、矢羽の下に別の内容を積む。
- **P25**：節目（◆）と完了時期を決める作業を明示する。失敗：全ての棒を同じ色にする。
- **P26**：導入前の現状に提案物を混ぜない。改善後は別ページで同じレーンを使って示す。失敗：矢印が交差して流れが読めない。
- **P27**：見通しの期間は「（予測）」と明記し、各シナリオの前提を必ず並べる。失敗：前提のない3本の線。
- **P28**：影響の大きい順に並べ、基本ケースの値を書く。失敗：変動幅の前提（±10%など）が書かれていない。
- **P29**：演算子（＝×−＋）と各箱の値を書く。値は検算表と一致させる。失敗：式が成り立たない（掛け算の結果が合わない）。
- **P30**：兆候は「何を見れば分かるか」を数値の閾値で書く。失敗：兆候欄にリスクの言い換えを書く。
- **P31**：濃淡はグレー3段階に限り、凡例で意味を書く。失敗：多色の信号色（赤黄緑）で塗る。
- **P32**：依頼や合意事項が実際にあるときだけ使う。決定後の動きに期限を書く。失敗：選択肢を並べるだけで推奨がない。
- **P33**：目盛りを必ずそろえる。失敗：小図ごとに目盛りが違い、大小を見誤らせる。

- **P34**：後続ページのトラッカーと同じ番号・言葉を使う。失敗：目次とトラッカーの言葉がずれる。
- **P35**：進め方の順番でなく、答えを決める要素で分ける。失敗：「調査→分析→提言」のような工程で分解する。
- **P36**：差の列を必ず設ける。失敗：現状と目標を並べるだけで差を読ませない。
- **P37**：合計を最下行に置き、検算する。失敗：打ち手の効果に重複があり合計が過大になる。
- **P38**：算定の前提を補足に書き、2つの数値の内訳を同じ行立てで並べて差の所在を示す。失敗：比べる2つの数値の定義が違う、数値の下が空く。
- **P39**：割合が1桁や90%台なら棒グラフにする。
- **P40**：円の面積を値に比例させる（直径ではない）。失敗：直径を比例させ、差を誇張する。
- **P41**：合計を棒の上に書く。構成比だけならP05を使う。
- **P42**：屋根の箱は使わず線と文字で。失敗：塗りつぶしの家の絵になる。
- **P43**：課題のあるセルだけ短く書く。失敗：全セルを埋めて焦点がぼやける。
- **P44**：各セルは短い動詞句。セルを1つずつ箱で囲まず、行の線と列の点線で区切り、鍵のセルだけ淡い紺の面で立てる。公開資料では時代×論点で制度の変遷を示す使い方もある（BCG02-p44）。
- **P45**：循環の起点（悪循環なら断ち切る点）を示す。
- **P46**：各段の下に値を置き、自社の位置を示す。
- **P47**：分岐の条件は数値の閾値で書く。
- **P48**：各動向に数字1つと出所を添える。4つの枠は箱で囲まず「区分＋見出しの線」で始める。失敗：数字のない一般論の羅列、4つの箱を枠線で並べる。
- **P49**：件数・期間・対象を数字で書き、行見出し（対象・時期・使った章）で各調査を本資料のどこで使ったかを示す。公開資料では調べ方を左から右へ箱でつなぐ（BCG02-p10）。失敗：大きな数字の下が空く。
- **P50**：状態は記号と言葉で示し、信号色を使わない。
- **P51**：画面上の番号と手順の番号を対応させる。個人情報はぼかす。
- **P52**：円は塗らずに線で描く。
- **P53**：発言者は属性で示し、個人名は出さない。主張と発言を左右で1対1に対応させる形もある（BCG01-p36）。
- **P54**：帯の中は「声」と「示唆」に分け、示唆の一文だけ紺。
- **P55**：基準線（平均＝100など）を必ず引く。

- **P56**：時間の横棒は議題の長さを比べるためのもの。合計時間で締め、資料のページ番号を添える。失敗：時間だけで、議題ごとに何を決めるかが書かれていない。
- **P57**：工夫は動詞で書き、効く目的を英字バッジで示す。どの目的にも効かない工夫は載せない。失敗：目的と工夫を線で全部つなぎ、線が交差して読めない。
- **P58**：印は✓だけを使い、該当数を最下行に置く。失敗：○△×を混ぜて、印の意味が凡例なしでは読めない。
- **P59**：外れた行は消さずにグレーで残し、どの条件で外れたかを×で示す。上に件数の推移を矢印で添える。失敗：残った候補だけを載せ、絞り込みの妥当性が検証できない。
- **P60**：差の大きい順に並べ、差の列を右端に置く。前の時点は淡く、後の時点は濃く塗り、凡例は上に1行で。失敗：2つの棒グラフを並べて差を読ませる。
- **P61**：項目名と値を線の両端に直接書き、ラベルが重なる場合は少しずらす（目盛りは書かない）。失敗：項目が9本以上で線が絡む。
- **P62**：目標までの帯、実績の棒、目標の縦線の3つだけで描く。達成率を右端に太字で。失敗：信号色で達成・未達を塗り分ける。
- **P63**：件数の降順に並べ、累積構成比の線と80%などの目安線を引く。失敗：「その他」を途中に置き、降順が崩れる（「その他」は最後）。
- **P64**：棒は中央にそろえ、段階の間の移行率を右の列にまとめる。最も低い移行率だけを大きく紺で。失敗：人数だけを並べ、どこで離れるかを読ませない。
- **P65**：階級の幅をそろえ、中央値（平均）の線に名前を付ける。失敗：階級が多すぎて棒が細くなる（12本まで）。
- **P66**：段階は矢羽で、行は「行動・不満・打ち手」の3つに絞る。不満の行と打ち手の行を同じ列で対応させる。失敗：段階ごとに長文を書き、表が文字で埋まる。
- **P67**：上下の線は指揮、点線は助言と凡例で示す。箱には役割を1行、構成員を1行だけ書く。失敗：人名を並べた組織図になり、役割が分からない。
- **P68**：フェーズの境目に判断点（◆）を置き、判断の内容を書く。各棒は短い動詞句。失敗：全ての棒を同じ色にし、完了時期を決める作業が分からない。
- **P69**：出来事は上下交互に置き、各12字以内。期間のある出来事は軸の上に帯で示す。失敗：年の間隔を等間隔にせず、出来事の間隔が誤って見える。
- **P70**：カードの項目の行の高さを全カードでそろえ、最も言いたい数値を大きく書く。失敗：推奨案のカードだけ項目が多く、公平な比較に見えない。
- **P71**：象限の名前を四隅に書き、動かしたい関係者に目指す位置への点線矢印を付ける。右に巻き込み方を書く。失敗：関係者を置くだけで、次に何をするかが書かれていない。
- **P72**：番号と区分名は一覧のページと一字一句そろえ、左の主張はメッセージの言い換えでなく根拠の一点を書く。パネルを濃い塗りの箱にしない（紺の番号と縦線で区切る）。失敗：番号だけ大きく、どの一覧の番号か分からない。
- **P73**：基準線の上に増える分、下に減る分。左端に増減それぞれの合計と差し引きを置き、合計を検算する。失敗：増減を赤と緑で塗り分ける、差し引きだけを示して中身を隠す。
- **P74**：円の面積を件数に比例させ、円の横に数字を書く。行と列の計を端に置く。失敗：直径を比例させて差を誇張する、凡例でしか数が読めない。
- **P75**：項目名は書かず、多い順の細い棒で形を見せる。上位の区切りに線を引き、その割合を注記する。右に読み取りを置く。失敗：項目名を全部書いて読めなくなる、上位の割合を書かない。
- **P76**：大分類は名前と小計を左に置き、範囲を縦の線で括る。大分類の間は全幅の線、行の間は細い線。失敗：大分類を濃い塗りの箱にして、塗りの面が増える。
- **P77**：原因は「未達の事実」でなく仕組みを書く（「乗客が少ない」でなく「時刻を別々に決めている」）。向きは見出しの行の三角で示す。失敗：原因の列が課題の言い換えになる。
- **P78**：両側の要因は同じ単位・同じ期間でそろえ、差し引きを下に1行で書く。失敗：片側だけ要因を細かく割って、力の大きさを誤認させる。
- **P79**：指標の列ごとに基準線（0）と縮尺をそろえ、値は棒の先に直接書く。行の見出しはアイコン＋名前で、行の区切りは細線1本。読み取りは1行2行以内。失敗：列ごとに縮尺が違い、行どうしの大小を見誤らせる。読み取りが図の値と関係のない一般論になる。
- **P80**：単価の安い順に左から並べ、0の線と目標の縦線を必ず引く。ラベルは主な打ち手だけに引き出し線で付け、段をずらして重ねない。失敗：打ち手の種類で棒を多色に塗り分け、どこが言いたいのか分からない。棒の幅を量に比例させず、ただの棒グラフになる。
- **P06（追記）**：要因の下に「全体の増減に占める割合」を丸の印で並べると、効いている要因が数字で読める（MCK04-p13）。割合の合計は100%になるよう検算する。
- **P54（追記）**：帯は2〜3段に分け、各段を「太字の一文＋本文2〜3行」で書く（MCK04-p9・p17・p27）。帯の幅は本体の約3分の1。

## 公開資料から学んだ作法（2026-10-20、MCK01〜03・BCG01〜02の506ページから）

- メッセージラインは1〜2行の結論文が基本（MCK・BCGとも）。アンケートの頁は冒頭に何の結果かを短く示す
- 本体の色は主色の濃淡＋グレーの2〜3色に抑え、赤は採用案や「ここを見る」1か所だけに使う
- 章・節の区切りは目次を再掲し、今の章だけ反転・強調するトラッカー方式を徹底している
- 定量の図は左、定性の声や示唆は右の淡色パネル（帯）という左右分担を繰り返し、視線の流れを一定にする
- 図と本文は丸番号・英字のバッジで対応させ、左右2段の間には矢印を置く
- グラフは目盛りを省いて数値を直接書き、変化量は＋ppや楕円の注記で別に示す
- 事例・国・類型ごとに同じレイアウトを繰り返すモジュール構成で、読み手は型を一度覚えれば中身だけを追える
- 出所・注記は左下に小さく、設問・n数はタイトル直下の見出し行に書く。ページ番号は右下
- 本編の主張ページは文字を抑え、付録の一覧表は参照用として高密度と割り切っている
- 型ごとの手本は、上の一覧の「参考ページID」と catalog.xlsx の「ページ台帳」（80ページ分）を参照する。ページ画像はPCの `参照ライブラリ/pages/` にある。

## デザインを格上げする作法（2026-10-21）

「規定は守っているのに垢抜けない」ページを直すための作法。外資系コンサルの公開資料（台帳の評価Aのページ）に共通する見せ方を、`rules/slide-rules.md` の範囲で具体的な数値にしたもの。ルールと食い違う場合はルールを優先する。

| 注目の行はBlue5の帯で | 注目の行・列はBlue5（#C1DDF1）の帯を敷き、文字もNavyの太字にする。帯は1枚に1か所 | P56、P58、P59 |
| 言いたい数字を主役にする | 言いたい数値は Arial 太字 20〜32pt、ラベルは14ptのグレー。数字の横に単位を繰り返さず、見出しの括弧書きにまとめる | P64、P70、P38 |
| 凡例をやめて直接書く | 系列名と値は線の端・点の横に直接書く。凡例が要るなら図の上に1行で、色の点＋名前 | P60、P61 |

## Jinba consulting-pptx-skill から学んだ作法（2026-10-22）

`github.com/carnot-tech/jinba-consulting-pptx-skill`（MIT License）の規約と見本帳（62型）を読み、本リポジトリの見本と比べて分かった差。ルールとしては `rules/slide-rules.md` のH章に入れた。

- 見本帳は、色をほぼ使わず、**見出しの下の太い線・行の間の細い線・余白**だけで構造を作っている。本リポジトリの見本は、項目を1つずつ線の箱で囲む型（P11・P22・P23・P44・P48）が多く、箱の線と見出しの線が混ざって階層が読めなかった → 「見出し＋線」に統一。
- 線の階層が逆転していた（スライドタイトルの線がGray1 0.5pt、表の見出しの線がGray2 1pt）→ スライドタイトルの線を最も太く濃くした（H-2）。
- 矢羽・数値・調査の型で、本体の下3〜5割が空いていた（P13・P20・P24・P38・P49）→ 行見出し（期間・担当・条件、対象・時期・使った章）や内訳を足して埋めた。引き伸ばしでは埋めない（H-7）。
- 塗りの帯に枠線を重ねていた（P01の提言、P32の判断事項）→ 塗りか枠の一方にした（H-3）。
- 見本の値が【】の空欄のままだと、文字量と空きの判断ができない → P01〜P55も架空の値（みなと市のバス事業）に置き換えた（H-15）。
- 規約を機械チェックとページ画像の目視の両方で守らせる仕組み（版面の空き・重なり・塗りの数）→ `scripts/check_deck.py` に版面の検査を加えた。

## 公開資料から学んだ作法（2026-10-27、MCK04・MCK05の51ページから）

マッキンゼーが経済産業省の会議で発表した2本（GX推進小委員会 2022年、定置用蓄電システム普及拡大検討会 2024年）を分類した。図・文言・数値は写さず、見せ方だけを型と作法に反映した。

| 作法 | 具体的に | 参考ページID |
| --- | --- | --- |
| 右3分の1の帯で読み取りを集約する | 本体の左約3分の2に図、右約3分の1を淡い面の帯にし、「太字の一文＋本文」を2〜3段。段の間は細線。図の中に説明文を書き込まない | MCK04-p9・p17・p26・p27 |
| 行をそろえて小さな図を並べる | 行の見出し（アイコン＋名前）、指標ごとの小さな棒の列、読み取りの列を、行の区切り線で横一列にそろえる。列ごとに基準線と縮尺を共通にする | MCK04-p10・p11・p12 |
| 要因の割合を丸の印で添える | ウォーターフォールの要因の下に「全体に占める割合」を丸の印で並べ、効いている要因を数字で示す | MCK04-p13・p22 |
| 合計は棒の上の丸の印で | 積上げ棒の合計を、棒の上の丸の印（濃い塗りに白抜きの数字）で示し、内訳の数字と区別する | MCK04-p30 |
| 差は括弧と%で | 2つの棒の差を、右側の括弧と「−17%」の注記で示す。差の数字だけ太字 | MCK04-p26・p27 |
| 平均の線に記号を付ける | 平均・基準の横線の右端に「Ø 36」のように値を付け、線の意味を凡例に頼らず示す | MCK04-p7・p31 |
| 章の目次を各章の扉で再掲する | 目次を章扉に再掲し、今の節だけ塗りの帯に白文字で反転する。細目（― 分析の手法 など）も同じ字下げで残す | MCK04-p3・p8・p14 |
| 単位は見出しの次の行に | 図の見出しを太字1行、単位と期間を次の行に細字で書く（「米ドル/トンCO2e」「2017〜50」） | MCK04-p9・p12・p30 |
| 対象を絵や旗で示すのは右上に小さく | 国・シナリオの区別は右上の小さな旗や「ベースケースシナリオ」の小さな文字で示し、本体の色を増やさない | MCK04-p15・p30・p31 |

採らないもの：MCK05 は濃い紺の背景に白文字・赤や水色の大きな数字で描かれている。本リポジトリの配色（白地・指定色、B-3）に合わないため、配置（シナリオの小図＋前提の行、MCK05-p5）だけを参考にした。MCK04 の水色・青の多色の塗り分け（部門別の積上げ）も、紺1点の原則に合わせて採らない。

## 手本と測って近づけた作法（2026-10-28、MCK04 との比較から）

`scripts/compare_reference.py` で MCK04（36ページ）と見本デッキ（型の見本と完成例の104ページ）を同じ物差しで測り、差の大きい項目から直した。手本どうしの類似度（ページを無作為に半分に分けて比べた値、76.7%）に対する達成度は 77.7% → 95.0%。フォントの段差（B-2）と配色（B-3）は変えていない。

| 作法 | 具体的に | 効いた項目 |
| --- | --- | --- |
| 読み取り帯を型の見本の半数に置く | 図を左約3分の2に縮め、右に淡いグレー（#F2F2F2）の帯（幅3.3インチ。2026-10-30 に Blue4 から変更）を置いて「太字の一文（14pt）＋根拠3文（12pt）」を2段。根拠は図の数字→比べた結果→次の打ち手の順。型ごとの文は `scripts/sample_readouts.js`、完成例はメッセージの書き出しで選ぶ | 文字数・図の上の文字 |
| 根拠は2行で終わらせない | 帯の根拠は1段80〜100字。手本の本体の文字は中央値約320字で、図だけのページ（約190字）の倍近い | 文字数 |
| 注記は型ごとに要るものだけ、全幅で2行まで | 定義・算定の前提・調査の条件を1〜2文。無い型は出所だけ（`scripts/sample_notes.js`）。注記の枠は本体の全幅（2行で約190字まで） | 注記の量 |
| 言いたい行に淡い帯を敷く | 表・一覧で結論の行の背面に淡いグレーの帯を敷く（`band()`。最背面に回るので後から描いてよい）。紺の文字と重ねても紺は1か所のまま | 塗りの色数 |
| 縮めても1行のラベルは幅を保つ | 帯を置くために図を縮めるとき、高さ0.5インチ以下の文字の枠は幅を縮めない（折り返して2行になるのを防ぐ） | はみ出し |

帯を置かない型：横幅が要る型（計算ロジック P29、年表 P69、選択肢カード P70、コストカーブ P80）、アイコンを置く型（P12・P67）、右端に年度の列がある型（P19）、自前の読み取り列を持つ型（P10・P21・P31・P54・P75・P79 など）。

測っても縮まらなかった差：塗りの色数（手本は3割のページで5色以上。紺1点の原則（G-6）のため、青の濃淡で塗り分けることはしなかった）と、図の広さ（帯の面も図に数えるため手本より広い）。
