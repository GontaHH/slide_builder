# パターン定義（P01〜P20）

consulting-slide-builder が各スライドの型を選ぶための定義。見本は同じフォルダの pattern-deck.pptx の同じIDのスライド。型は「発想帳」であり、伝えたいことを先に決めてから選ぶ。
座標は標準サイズ（27.52×19.05cm = 780×540pt）基準。共通枠（メッセージブロック・スライドタイトル・出所・ページ番号）は全パターン同じ位置。

## 共通枠

| 領域 | 位置（pt） | 内容 |
| --- | --- | --- |
| メッセージブロック | 上端20〜92、左22.7〜757 | 紺の縦バー（幅4）、章名11pt灰、メッセージライン20pt太字紺2行 |
| 区切り線 | y=101 | 細いグレー線 |
| スライドタイトル | y=112〜134 | 14pt太字黒＋単位・期間11pt灰、下に細線 |
| 見本ステッカー | 右上 y=112 | 11pt灰の細枠（本番では「試算」等に差し替えるか削除） |
| 本体 | y=144〜486 | エクジビット1つ（2つなら左右） |
| 注記・出所 | 左下 y=494 | 9pt灰 |
| ページ番号 | 右下 | 9pt灰 |

## 章（役割）による分類

| 章 | 役割 | 型 |
| --- | --- | --- |
| A 枠組み | 全体像・論点を示す | P01, P02, P14 |
| B 数字で証明 | 定量で主張を裏付ける | P03〜P10, P18, P20 |
| C 比較・評価 | 選択肢や対象を比べる | P11, P15, P16 |
| D 構造で通す | 関係・仕組みを示す | P12, P17 |
| E 進め方・計画 | 手順・日程を示す | P13 |
| F 提示・締め | 提言・判断を求める | P19 |

## パターンごとの作法と、よくある失敗

- **P01**：章の結論を並べるだけで議論の全体が分かること。失敗：箇条書きの羅列で、どれが結論か分からない。
- **P03／P09**：CAGRや差分の注釈は1つだけ。失敗：全ての棒を同じ濃い色にする、目盛り線を残す。
- **P04**：必ず降順。失敗：五十音順や地域順で並べ、比較が読めない。
- **P05／P18**：系列名は凡例ではなく右端に直接書く（P18は上部の凡例で可）。失敗：系列が6つ以上。
- **P06**：始点・終点は濃いグレー、要因は中間のグレー。増減は「＋」「−」で示し、赤緑で塗り分けない。
- **P07**：規模かシェアの片方しか議論しないなら、P04やP05で足りる。
- **P10**：チャート上の番号と右欄の番号を対応させる。失敗：右欄が長文になる。
- **P11**：2つのエクジビットは必ず左右。上下に積まない。左右の見出しの高さをそろえる。
- **P12**：アイコンは単色の線画で統一。矢印には流れるもの（資金・データ・人）を書く。失敗：塗りつぶしの色付き箱を並べる。
- **P13**：判断点（◆）と条件を書く。失敗：工程を並べただけで、何を決めるかが分からない。
- **P14**：演算子（×＋）を書く。失敗：MECEでない分解。
- **P15**：軸の定義と象限の意味を書く。失敗：軸の向き（高・低）が不明。
- **P16**：評価基準は注記で定義する。失敗：全セルに色を付ける。
- **P17**：成功の鍵を1行で書く。失敗：事例の説明が長文になる。
- **P19**：施策は動詞で終え、番号と着手時期を付ける。
- **P20**：数値の算定前提を補足（11pt）に書く。
