# 手本の実測値と、作図の既定値

公開資料の実物を測った値と、そこから決めた作図の既定値。座標を目分量で決めず、ここの値を使う（rules/slide-rules.md I-5・I-6）。
実物の画像が読めない環境（クラウドなど）では、この表を「実物と並べて比べる」ときの相手にする。

## MCK04（マッキンゼー「日本の脱炭素化への道筋」GX推進小委員会 2022年、38ページ）の実測

測り方：PDF（960×540pt、16:9）から文字の大きさ・位置、線の太さ、棒の幅と隙間を pdfplumber で読み取った（p9・p10・p12・p13・p17・p22・p23・p26・p27・p30・p31）。
本リポジトリの版面（780×540pt、A4横）とは**高さが同じ**なので、文字の大きさ（pt）はそのまま比べられる。横方向の長さは0.81倍して比べる。

## 実物と並べて比べる手順（I-5）

1. 自分のページと参考ページを、同じ高さの画像にする（例：`pdftoppm -r 60 -png`）。
2. 2枚を左右に並べた1枚の画像を作って見る（Pythonの PIL で横に貼り合わせる）。
3. 見る順：①メッセージ欄と本体の高さの比 ②本体の文字の段差 ③図が本体に占める広さ ④線の太さ ⑤棒の太さと隙間 ⑥注記の量。
4. 差を「ページ・項目・直したこと」で最終報告の洗練パスの記録に書く。
