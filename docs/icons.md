# アイコン集

関係図・体制図で主体や流れを示すための、単色の線画アイコン70種。SVG は `templates/icons/` にあり、見本は `patterns/pattern-deck.pptx` の I01〜I04。

- 出典：[Lucide](https://lucide.dev)（v0.460.0、ISCライセンス。`templates/icons/LICENSE`）。線の色をGray2（#7F7F7F）、線幅を1.5に整えた。
- PowerPoint では「挿入→画像→このデバイス」で SVG を挿入し、「グラフィックス形式→グラフィックの枠線」で色を変える。
- 足りないアイコンは、同じ Lucide から選んで同じ手順で整える（絵柄の太さがそろう）。別の素材集を混ぜない。

## 使い方の決まり

| 決まり | 理由 |
| --- | --- |
| アイコンは関係図・体制図・カスタマージャーニーなど、主体や分野を見分ける必要がある図だけに使う | 飾りのアイコンは視線を散らす（B-6） |
| 必ず下か右に短い名前（14pt）を添える。アイコンだけで意味を伝えない | 絵柄の解釈は人によって違う |
| 色はGray2（#7F7F7F）。Navyは、変化する主体や注目する分野の1つだけ | 強調は1スライド1点（B-3） |
| 1枚に使う種類は6つまで。大きさをそろえる（関係図では0.5〜0.6インチ） | 要素は6つ以内（C-3） |
| 円の線（グレー1pt、注目は紺2pt）で囲んでもよいが、塗りつぶさない | 塗りの丸を並べると強調が分散する |
| 多色のイラスト、写真の切り抜き、各社のロゴは使わない | B-6 |
