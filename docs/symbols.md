# 記号集

スライドで使う矢印・線・符号・印の決まり。見本は `patterns/pattern-deck.pptx` の S01〜S04 にあり、図形はそこからコピーして使う。
色と太さは `rules/slide-rules.md` の B-3（配色）の指定色（Navy・Blue1〜5・Gray1〜2、文字は#3F3F3F）に従う。**紺にするのは1枚に1か所だけ**で、矢印・線も例外ではない。

## 1. 矢印（S01）

公開資料 MCK04（マッキンゼー「日本の脱炭素化への道筋」2022年）の描き方に合わせた（2026-10-30）。図形は `scripts/mck_marks.js` で描く。PowerPoint の線の矢印（矢じりが小さく潰れる）と、ブロック矢印の図形は使わない。

| 名前 | 見た目 | 使う場面 | 決まり |
| --- | --- | --- | --- |
| 流れの矢印 | Gray2（#7F7F7F）1pt の線＋小さな塗りの三角の頭（`flow`） | モノ・お金・データ・人の流れ | 線の上か横に「何が流れるか」を書く（MCK04-p5） |
| 太い矢印 | 文字色（#3F3F3F）4.5pt の線＋大きな三角の頭（`bold`） | 変化の向き（伸びる・転じる・下がる） | 1枚に1本。紺にするのは、その矢印が1枚の主役のときだけ（MCK04-p21） |
| 点線の矢印 | 流れの矢印の破線 | 将来の計画、目指す位置、間接的な関係 | 実線と同じ頭を付ける |
| 双方向の矢印 | 両端に頭 | 相互のやり取り | 片方向で言えるなら片方向にする |
| 合流の矢印 | 細い線を1点に集め、そこから1本の矢印（`merge`） | 複数の要素が1つにまとまる | 分岐はこの逆向き（MCK04-p5） |
| 循環の印 | アイコン refresh-cw（グレー） | 繰り返し、好循環・悪循環 | 矢印で円を描かない。循環の起点を1つ決めて示す（P45） |

使わないもの：ブロック矢印の図形、二重の矢羽を並べた矢印、曲線を何本も交差させた矢印、色付き・影付きの矢印。

## 2. 線と注釈（S02）

| 名前 | 見た目 | 使う場面 | 決まり |
| --- | --- | --- | --- |
| 差の矢印 | 高い棒の上端から細線を伸ばし、縦の細い矢印を低い棒の上端まで下ろす（`drop`） | 2本の棒の差 | 差は「−17%」「−6pt」を矢印の右に太字で（MCK04-p5・p26）。括弧は使わない |
| 伸び率の矢印 | 文字色1pt の斜めの矢印 | 時系列の伸び率の注釈 | 上に「年平均＋6.7%」と書く。1枚に1つ（D-2） |
| 平均の線 | 文字色0.75pt の横線＋右端に「Ø 36」 | 平均・基準 | 値を線の端に書き、凡例に頼らない（MCK04-p31） |
| 段の区切り | 縦の区切り線の上に、白い丸＋細い「＞」（`step`） | インプット→処理→アウトプットのように左から右へ進む段 | 下へ進むときは「∨」（MCK04-p5） |
| 因果の三角 | Gray1 の塗りの細い三角（`cause`） | 左右のエクジビットの間の強い因果 | 1枚に1つまで。線や枠を重ねない |
| 判断点 | 文字色の◆ | ガント・ロードマップの節目、判断の時期 | 判断の内容を下に書く（P13、P25） |
| 矢羽 | 五角形＋シェブロン | 工程・段階の順序 | 今の段階だけ紺、他はGray1（P24、P66、P68） |
| 区切りの細線 | Gray1 0.5〜0.75pt | 表の行、要素の区切り | 囲み・塗りの代わりに使う（B-3） |

## 3. 数値の符号（S03）

| 記号 | 意味 | 決まり | 例 |
| --- | --- | --- | --- |
| + − | 増減の符号 | 負の数は「−」（マイナス記号）で書く。**▲・△を符号に使わない**（会計資料の「▲＝マイナス」と、増減の向きの「▲＝増加」が紛れるため） | +1.9、−0.3 |
| ▲ ▼ | 増減の向き | 表の中で向きだけを示すとき。数値の符号の代わりにしない | ▲ 増加 |
| pt | 比率の差 | 比率どうしの差は「pt」。「%」と書くと増減率と誤読される | 52%→46%は「−6pt」 |
| 倍 | 比較 | 「1.5倍」。同じ資料で「150%」と混ぜない | 平均の1.5倍 |
| – | 期間・範囲 | 見出し・表では「2015–2025年度」（エンダッシュ）。文中の範囲は「〜」 | 3–5件 |
| → | 変化の前後 | 「32→24本」。結論を示す「⇒」は使わず、言葉で書く | 2.1→5.2億円 |
| × ＝ − ＋ | 計算の演算子 | 計算ロジック（P29）で使う。式は左から右へ1方向に書き、値は検算表と一致させる | 単価×人数＝収入 |
| % | 構成比・率 | 小数点以下1桁まで（D-3） | 12.4% |

単位は見出しの括弧書きにまとめ、数値の横に繰り返さない（D-2）。数値は Arial で、同じ行の和文と同じ大きさにする。

## 4. 印と表記（S04）

| 記号 | 意味 | 決まり |
| --- | --- | --- |
| ○◔◑◕● | 評価（ハーベイボール） | グレーで描き、凡例で5段階（または3段階）の基準を定義する。推奨の列は紺の細枠で囲み、ボール自体は紺にしない。信号色（赤黄緑）は使わない（P16） |
| ✓ × | 該当・対象外の印 | 対象と対象外を並べるときは細い丸で囲む（MCK04-p4）。表の中では✓だけを使い、同じ表で○×と混ぜない |
| ○ × | 条件を満たす／満たさない | 条件で絞り込む表（P59）で使う。外れた行は文字をグレーにする |
| 番号・区分の丸 | 図と本文の対応、論点の番号 | 論点の番号は文字色の塗りの丸に白抜きの数字、区分（A・B）は白い丸に細い線（MCK04-p5・p21、`badge`）。丸数字の文字（①②）は使わない。紺にするのは強調する1つだけ |
| 注）1. | 注記 | 本文の該当箇所に肩番号（1, 2…）を付け、「注）1. …」を出所の上に書く（D-3） |
| ― | 該当なし・対象外 | 空欄にせず「―」を置く。「0」（値がゼロ）と区別する |
| （見込）（予測） | 推計値 | 年度の後ろに付け、棒・線は実績より淡い色にする（D-2） |
| 【要確認】 | 作業表示 | 根拠が未確認の箇所。仕上げ時にすべて解消する（D-3） |

## 5. 使わない記号

| 記号 | 理由 | 代わりに |
| --- | --- | --- |
| ⇒ ∴ ∵ | 論理の飛躍を記号でごまかす | 「だから」「その結果」など言葉で書く |
| ※ | 注記の書式が資料ごとにぶれる | 「注）」と肩番号 |
| ①②③（文字） | フォントで形が崩れる | 図形の番号バッジ |
| 絵文字、★☆、♪ | 装飾で意味がない（B-6） | 使わない |
| ≒ | 読み手により意味がぶれる | 「約」 |

## パーツ集（S05・S06、2026-10-22 追加、2026-10-30 改訂）

自作の書式（HG_pptFMT）のパーツ集を指定色で描き直したもの。2026-10-30 に矢印を MCK04 の描き方に替え、色は文字色とグレーを基本にした。図形は見本デッキの S05・S06 からコピーして使う。

| 区分 | パーツ | 決まり |
| --- | --- | --- |
| 文字の階層 | 見出し「■」（14pt太字）、第1階層「•」、第2階層「–」（14pt） | 記号は段落の書式で付け、本文に打たない（H-6） |
| 箱 | 濃い塗り（白文字）、淡い塗り、上線だけ、枠線だけ × 強調（紺）・基本（グレー） | 基本は淡いグレーの塗りと上線の2つ。紺の塗りは1枚に1か所だけ |
| 矢印と印 | 流れ、太い矢印、下向き、段の区切り、比較（塗りの丸に白抜きの↔、MCK04-p21）、因果 | 文字色とグレーで描く。紺は主役の1つだけ |
| 注記の吹き出し | 淡いグレーの箱＋細い引き出し線 | 図の該当箇所から線を引く。1枚に2つまで。文字は11pt（補足扱い） |
| 番号 | 四角・ひし形・丸 × 基本（文字色）・強調（紺）（白抜きの数字） | 後で参照するときだけ振る。形は1資料で1種類。紺は強調する1つだけ |
| 演算子 | ＋ − × ÷ ＝ ≒（白い丸に細いグレーの線） | 計算式（T15、P29）で使う |
| 状態の印 | ✓ ↑ ↓ ？ →（グレーの丸に白）、循環 | 凡例で意味を書く。信号機の3色にしない |

元の書式の赤・オレンジの箱は、指定色（rules B-3）に無いため入れていない。悪化・未達を強調するときは反対色（#D73232）の文字で示す。
