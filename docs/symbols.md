# 記号集

スライドで使う矢印・線・符号・印の決まり。見本は `patterns/pattern-deck.pptx` の S01〜S04 にあり、図形はそこからコピーして使う。
色と太さは `rules/slide-rules.md` の B-3（配色）の指定色（Navy・Blue1〜5・Gray1〜2、文字は#3F3F3F）に従う。**紺にするのは1枚に1か所だけ**で、矢印・線も例外ではない。

## 1. 矢印（S01）

| 名前 | 見た目 | 使う場面 | 決まり |
| --- | --- | --- | --- |
| 流れの矢印 | Gray2（#7F7F7F）1pt、三角の矢じり | モノ・お金・データ・人の流れ | 線の上か横に「何が流れるか」を14ptで書く（資金、データ、人など） |
| 強調の矢印 | Navy 1.75pt | 変化する流れ、メッセージが指す流れ | 1枚に1本まで |
| 点線の矢印 | Gray2 1pt の破線 | 将来の計画、目指す位置（関係者マップ）、間接的な関係 | 実線の矢印と同じ図の中で意味を混ぜない |
| 双方向の矢印 | 両端に矢じり | 相互のやり取り | 片方向で言えるなら片方向にする。「連携」を表すだけの双方向矢印は使わない |
| 合流の矢印 | 2本の線が1点に集まり、1本の矢印になる | 複数の要素が1つにまとまる（統合、一元化） | 分岐はこの逆向き。分岐の条件は数値の閾値で書く（P47） |
| 循環の矢印 | Gray1の塗りの円弧矢印 | 繰り返し、好循環・悪循環 | 循環の起点（断ち切る点）を1つ決めて示す（P45） |

使わないもの：太いブロック矢印を並べた図、曲線を何本も交差させた矢印、色付きの矢印、影付きの矢印。

## 2. 線と注釈（S02）

| 名前 | 見た目 | 使う場面 | 決まり |
| --- | --- | --- | --- |
| 因果の三角 | グレーの塗りの三角＋細い「＞」の線（HG_pptFMT の形、S02） | 左右のエクジビットの間の強い因果 | 1枚に1つまで。弱い関係には置かない（C-1） |
| 矢羽 | 五角形＋シェブロンを横に並べる | 工程・段階の順序 | 今の段階だけNavyの塗り、他はGray1（P24、P66、P68） |
| CAGRの矢印 | Navy 1.25pt の斜めの矢印＋率 | 時系列の伸び率の注釈 | 「CAGR +3.2%」のように率を添え、注釈は1枚に1つ（D-2） |
| 差分の括弧 | Navyの細い角括弧＋差 | 2点の差を示す | 「+2.1倍」「−21pt」の形で書く |
| 判断点 | 文字色（#3F3F3F）の◆ | ガント・ロードマップの節目、判断の時期 | 判断の内容を下に14ptで書く（P13、P25、P68） |
| 区切りの細線 | Gray1（#CCCCCC）0.5〜0.75pt | 表の行、要素の区切り | 囲み・塗りの代わりに使う（B-3） |
| 基準線 | Gray2か文字色の点線 | 平均＝100、目標、80%などの目安 | 線の端に「平均＝100」のように名前を書く（P55、P62、P63、P65） |

## 3. 数値の符号（S03）

| 記号 | 意味 | 決まり | 例 |
| --- | --- | --- | --- |
| + − | 増減の符号 | 負の数は「−」（マイナス記号）で書く。**▲・△を符号に使わない**（会計資料の「▲＝マイナス」と、増減の向きの「▲＝増加」が紛れるため） | +1.9、−0.3 |
| ▲ ▼ | 増減の向き | 表の中で向きだけを示すとき。数値の符号の代わりにしない | ▲ 増加 |
| pt | 比率の差 | 比率どうしの差は「pt」。「%」と書くと増減率と誤読される | 52%→46%は「−6pt」 |
| 倍 | 比較 | 「1.5倍」。同じ資料で「150%」と混ぜない | 平均の1.5倍 |
| – | 期間・範囲 | 見出し・表では「2015–2025年度」（エンダッシュ）。文中の範囲は「〜」 | 3–5件 |
| → | 変化の前後 | 「32→24本」。結論を示す「⇒」は使わず、言葉で書く | 2.1→5.2億円 |
| × ＝ − ＋ | 計算の演算子 | 計算ロジック（P29）で使う。式は左から右へ1方向に書き、値は検算表と一致させる | 単価×人数＝収入 |
| % | 構成比・率 | 小数点以下1桁まで（D-3） | 12.4% |

単位は見出しの括弧書きにまとめ、数値の横に繰り返さない（D-2）。数値は Arial で、同じ行の和文と同じ大きさにする。

## 4. 印と表記（S04）

| 記号 | 意味 | 決まり |
| --- | --- | --- |
| ○◔◑◕● | 評価（ハーベイボール） | グレーで描き、凡例で5段階（または3段階）の基準を定義する。推奨の列は紺の細枠で囲み、ボール自体は紺にしない。信号色（赤黄緑）は使わない（P16） |
| ✓ | 該当の印 | 索引付きチェック表（P58）で使う。同じ表で○×と混ぜない |
| ○ × | 条件を満たす／満たさない | 条件で絞り込む表（P59）で使う。外れた行は文字をグレーにする |
| 番号のバッジ | 図と本文の対応 | 丸数字の文字（①②）ではなく、円の図形に白抜きの数字（または英字）で作る。環境で崩れず、大きさをそろえやすい（P10、P57） |
| 注）1. | 注記 | 本文の該当箇所に肩番号（1, 2…）を付け、「注）1. …」を出所の上に書く（D-3） |
| ― | 該当なし・対象外 | 空欄にせず「―」を置く。「0」（値がゼロ）と区別する |
| （見込）（予測） | 推計値 | 年度の後ろに付け、棒・線は実績より淡い色にする（D-2） |
| 【要確認】 | 作業表示 | 根拠が未確認の箇所。仕上げ時にすべて解消する（D-3） |

## 5. 使わない記号

| 記号 | 理由 | 代わりに |
| --- | --- | --- |
| ⇒ ∴ ∵ | 論理の飛躍を記号でごまかす | 「だから」「その結果」など言葉で書く |
| ※ | 注記の書式が資料ごとにぶれる | 「注）」と肩番号 |
| ①②③（文字） | フォントで形が崩れる | 図形の番号バッジ |
| 絵文字、★☆、♪ | 装飾で意味がない（B-6） | 使わない |
| ≒ | 読み手により意味がぶれる | 「約」 |

## パーツ集（S05・S06、2026-10-22 追加）

自作の書式（HG_pptFMT）のパーツ集を、指定色で描き直したもの。図形は見本デッキの S05・S06 からコピーして使う。

| 区分 | パーツ | 決まり |
| --- | --- | --- |
| 文字の階層 | 見出し「■」（14pt太字）、第1階層「•」、第2階層「–」（14pt） | 記号は段落の書式で付け、本文に文字で打たない（rules H-6） |
| 箱 | 濃い塗り（白文字）、淡い塗り、上線だけ、枠線だけ × 紺・グレー | 基本は淡い塗りと上線の2つ。濃い塗りは1枚に1か所。塗りと枠線は重ねない（H-3） |
| 矢印（HG_pptFMT の形） | 4種類×右向き・下向き×強調・通常の4×4（S05）。①二重の矢羽：太い「＞」を2つ重ね、後ろはグレー・前は紺（通常は両方グレー）②三角＋線：グレーの塗りの三角に細い「＞」の線を重ねる（線が紺か灰）③丸：紺（通常はグレー）の丸に白抜きの細い「＞」④線：細い「＞」1本（淡いグレー）か2本（紺） | 紺は強調する1つだけ。図形は自由図形で、`scripts/hg_arrows.js` の `hgArrow()`・`hgCircle()` で描く。PowerPoint 標準の「シェブロン」「二等辺三角形」は使わない |
| 注記の吹き出し | 淡い塗りの箱＋細い引き出し線 | 図の該当箇所から線を引く。1枚に2つまで。文字は11pt（補足扱い） |
| 番号 | 四角・ひし形・丸 × 紺・グレー（白抜きの数字） | 後で参照するときだけ振る。形は1資料で1種類。丸数字の文字（①）は使わない |
| 演算子 | ＋ − × ÷ ＝ ≒（紺の丸に白） | 計算式（T15、P29）で使う |
| 状態の印 | ✓ ↑ ↓ ？ →（紺の丸に白）、循環 | 凡例で意味を書く。信号機の3色にしない |

元の書式の赤・オレンジの箱は、指定色（rules B-3）に無いため入れていない。悪化・未達を強調するときは反対色（#D73232）の文字で示す。
